# Electronic-Circuits--RC-Phase-Shift-Oscillator
## AIM:
To simulate a RC Pase Shift Oscillator and to verify the output.
## APPARATUS REQUIRED:
PC with LT Spice software

## SIMULATION PROCEDURE:

1. Open the LTspice software.
2. File → New Schematic.
3. Click the component symbol to browse and select the components.
4. Click OK and place the component.
5. Search for resistor from the component menu or from the tab icons.
6. Place the resistors.
7. Use **Ctrl + R** to rotate the components.
8. Use the wire symbol to connect the components as per the circuit diagram.
9. Right-click each component to assign the values.
10. Use the Run button to run the simulation.
11. Set the step time and click OK.
12. The output dialog box will open.
13. In the output dialog box, right-click and select **Add Traces**.
14. Node voltages and currents of each component will be displayed.
15. Select the required node voltages (e.g., **V(n001)**) to get the waveforms.
16. To get the voltage across a component, the trace name should include both nodes, e.g., **V(n001, n002)**.
